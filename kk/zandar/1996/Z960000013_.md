# Қазақстан Республикасы Президентiнiң "Салық және бюджетке төленетiн басқа да мiндеттi төлемдер туралы" Заң күшi бар Жарлығына толықтыру енгiзу туралы

Қазақстан Республикасы Президентiнiң "Салық және бюджетке төленетiн басқа да мiндеттi төлемдер туралы" 1995 жылғы 24 сәуiрдегi N 2235 Z952235_

Заң күшi бар Жарлығына (Қазақстан Республикасы Жоғарғы Кеңесiнiң Жаршысы, 1995 ж., N 6, 43-құжат; N 12, 88-құжат; N 23, 152-құжат; Қазақстан Республикасы Парламентiнiң Жаршысы, 1996 ж., N 1, 180, 181-құжаттар) мынадай толықтыру енгiзiлсiн:

34-баптың 1-тармағы мынадай мазмұндағы 7-тармақшамен толықтырылсын"

"7) салымшылардың қаражатын орналастырудан түскен табыс бойынша мемлекеттiк емес ерiктi зейнетақы қорлары"

Қазақстан Республикасының

Президентi
